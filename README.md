## 2. Descripción del proyecto

Este proyecto tiene como objetivo diseñar e implementar un sistema de información para apoyar y optimizar el proceso de aseguramiento metrológico, centralizando el registro, seguimiento y gestión de los equipos involucrados en el proceso.

La solución busca reducir actividades manuales, mejorar la trazabilidad de la información y facilitar el seguimiento de los equipos durante las diferentes etapas del proceso. Además, contempla la generación y distribución de información consolidada mediante herramientas del ecosistema Microsoft Power Platform.

## 3. Cliente

El proyecto se desarrolla en colaboración con la empresa Renault Sofasa, tomando como referencia su proceso actual de aseguramiento metrológico y sus necesidades de gestión de información.

## 4. Stack tecnológico

La solución está construida utilizando tecnologías de Microsoft Power Platform:

* Power Apps: desarrollo de la aplicación y las interfaces utilizadas para registrar, consultar y gestionar la información.
* Power Automate: automatización de flujos, notificaciones y procesos relacionados con la gestión metrológica.
* Adaptive Cards: presentación y distribución de información estructurada e interactiva, incluyendo información asociada al seguimiento e informes del proceso.
